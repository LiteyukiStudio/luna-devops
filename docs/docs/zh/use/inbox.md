# 消息盒子

消息盒子集中展示与你相关的平台消息和待处理请求。登录后可通过页面右上角的铃铛查看最近消息，红点数字表示未读数量；选择“查看全部”可进入完整消息列表。

## 查看和整理消息

- **全部**：查看尚未归档的所有消息。
- **未读**：只查看还未打开的消息。
- **待处理**：只查看需要你作出决定的请求。
- 打开消息详情后可前往关联资源，或将不再需要的消息归档。
- 使用“全部标为已读”可一次清除当前账号的未读提示。

消息内容可能来自项目空间成员变更、费用与归属调整、安全提醒、外部通知投递或平台公告。消息只对接收账号可见。

## 处理请求

需要你确认的请求会出现在“待处理”中。打开详情、核对发起人和关联项目空间后，可以接受或拒绝。平台会在执行前再次确认，处理完成后不能对同一请求重复操作。

项目空间费用归属转移属于高影响操作：接受后，该项目空间后续费用将归入你的账号。请先确认项目空间和发起人无误；不希望承担费用时请选择拒绝。平台启用二次验证策略时，接受前还需要完成 MFA 验证。请求已过期、项目状态已经变化或权限不再满足时，平台不会执行转移，并会提示重新发起。

## 消息盒子与外部通知

消息盒子用于当前登录账号在平台内阅读和处理信息；[通知](./notifications.md)用于按规则把平台事件发送到邮箱、Webhook 或协作工具。两者用途不同，可以同时使用。
