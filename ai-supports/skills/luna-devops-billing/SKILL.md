# 账单 Skill

先遵循 `luna-devops-cli`。当前命令目录没有 `billing` 分类，因此本 Skill 只用于定义查询维度、解释计量单位和规划管理员操作。

## 规划清单

1. 账户、周期、项目、应用和部署配置。
2. 构建、运行、存储、请求与出站流量用量。
3. meter、单位、单价、账本与余额变更的对应关系。
4. 异常计费所需的 usage、rate 和 ledger 证据。

## 风险

- 不通过 `api request` 查询或写入账单。
- 不自动充值、补偿、扣费或调整费率。
- 金额变更必须明确账户、金额、单位、生效时间和影响。
- 历史账单不因项目删除或后续调价而重写。
