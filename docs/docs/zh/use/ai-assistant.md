# AI 助手

AI 助手可以结合当前页面和你的平台权限，查询资源、解释状态、诊断故障，并协助完成部署和日常运维。

部署容器化应用时，如果项目同时支持网络数据库和 SQLite 等本地文件数据库，助手默认会先评估复用项目空间内兼容的网络数据库，其次考虑部署新的网络数据库；只有这些方案不适用时才建议本地文件存储。你明确指定的数据库方案始终优先。

回复生成期间，消息列表只会在你停留于最新消息时自动向下跟随；向上滚动查看历史内容会暂停跟随，滚回底部后自动恢复。

停止正在执行的任务后，助手会保留已经产生的对话内容，并把本轮标记为已取消；正常取消不会显示为模型生成失败。随后可以修改输入并重新发起任务。

如果你不了解服务器、容器化或 Kubernetes，直接说明“我是新手”“第一次部署”即可。助手会切换为逐步引导模式，用通俗说法解释每个概念，先确认项目类型、启动命令和端口，再帮你完成打包、上线和配置访问入口。

## 开始使用

平台管理员在“全局设置 → AI 助手”中填写 Provider 地址和 API Key，在“AI 模型目录”中添加模型名称、最大上下文 Token、最大单次输出 Token，以及输入、输出、缓存输入、缓存输出四项价格，然后启用助手。请使用 Provider 公开的保守能力值，且输出上限必须小于上下文上限。目录必须始终保留至少一个启用的模型：首个模型会自动启用，最后一个启用模型不能停用。默认允许所有已登录用户使用，也可以把使用范围切换为仅平台管理员。Provider 需要兼容 OpenAI `chat/completions` 接口，并支持流式输出和工具调用。

输入框左下角可以选择当前会话使用的启用模型。模型选择与会话绑定：新会话会记录创建时的模型，之后继续沿用；只有你在该会话中主动切换时，后续消息才会改用新模型，其他会话不受影响。任务运行期间不能切换模型；每个 Run 会保存模型名称、能力、四项价格和累计预算快照，因此管理员之后停用模型或调整配置不会改变已经创建的 Run。没有可用模型时，管理员需要先添加并启用模型。

模型服务或平台接口出现短暂的网络错误、超时、限流或服务端故障时，助手默认自动重试 5 次，并按指数退避等待。管理员可以在“高级运行设置”中调整为 0–10 次；设为 0 会关闭自动重试。已经开始向界面输出的流式回复不会自动重放，非幂等写操作也不会在执行结果未知时重复提交，避免产生重复内容或资源。

启用后，页面右下角会显示助手入口。你可以直接描述目标，例如：

- 检查某个应用为什么无法访问。
- 根据代码仓库生成部署配置。
- 查询最近失败的构建并给出修复建议。
- 创建、切换或管理会话。

桌面端可以拖动和调整助手窗口大小。窗口较窄时，会话目录以覆盖式抽屉打开；窗口足够宽时，目录会自动在左侧展开，并仍可通过顶栏的会话按钮收起。

会话目录按时间距离简化最近更新时间：当天只显示时分，当年较早日期显示月日时分，往年记录显示年月日时分。正在运行的会话会在时间旁显示状态指示，不占用标题空间。

打开较长会话时，助手会先显示最近的完整对话；向上滚动接近顶部时再加载更早内容，并保持当前阅读位置，避免一次加载全部历史影响打开速度。

长会话会保留完整聊天记录供回看，并在接近模型上下文容量前自动整理较早轮次的任务目标、约束、资源和待办。模型每次处理请求时会优先使用当前工作、近期原文与整理后的历史事实；较长任务不会因为聊天轮数增加而要求你新建会话。

管理员可以在高级运行设置中调整“上下文输入预算”，可配置范围为 64–2048K Token，默认是 1024K Token，以容纳日志分析和复杂 DevOps 诊断所需的较大上下文；单次回复的最大输出默认是 64K Token，允许按模型能力配置到 128K。它们表示单次模型请求的可用上限，不是每轮固定消耗；实际输入预算会按所选模型的上下文容量和输出预留自动收紧。

同一页面还可设置单个 Run 的累计 Token 和 Credits 上限，默认分别为 2,000,000 Token 和 10,000 Credits。Credits 上限同时覆盖普通输入、输出、缓存输入和缓存输出；用户个人钱包的可用余额仍是更小的上限。主回答、工具循环、摘要、标题和下一步预测都计入同一 Run。平台会在每次请求前自动收紧输出上限；如果上下文、Run 预算或钱包已不足，则不会发送模型请求。

单个 Run 还受平台工具调用兜底上限保护，默认 256 次，可在 32–2048 次之间配置。这个高位上限用于截断重复的确定性失败或无新信息查询，不是普通工作流应追求的调用额度；达到上限时助手会明确停止原因，不会把未完成任务报告为成功。运行中的合法异步任务仍可按其权威状态继续检查。

输入框底部只显示一个上下文圆环，表示最近一次主回答模型调用的上下文占用。将鼠标移到圆环上或聚焦圆环，可以同时查看上下文用量和当前 Run 的累计 Token 预算用量、各自上限与百分比；重新打开会话后，页面会从权威时间线恢复最近一次用量。

“高级设置”中还可以按分类调整 Agent 内部参数：上下文与压缩（压缩触发/目标比例、保留近期轮次、摘要预算等）、模型与执行（回复最大输出 Token、Run 最大模型轮次、输入大小上限、跳转动作有效期）以及工具结果与卡片（工具结果上下文预算、交互卡片修复上限）。每项都提供平台默认值并由平台动态下发，普通部署保持默认即可，不建议随意调整。

升级后如果数据库中保留了超出当前范围或格式不正确的旧运行参数，平台不会自动改写这些存量值，也不会因此阻止 Agent 启动；实际运行会对该项使用当前平台默认值。管理员下一次提交该参数时必须修正到设置页标注的有效范围。Provider 地址、模型能力目录和工具契约不会被猜测或静默修正，这些结构不完整时仍会拒绝启动，避免请求发往错误目标或使用虚假的模型容量。

需要撤销运行参数调整时，点击“保存配置”旁的“恢复默认”。该操作只恢复 Agent 的运行、上下文、模型执行和工具预算参数，不会修改 Provider、API Key、使用范围、可观测或代理配置；确认页面数值后仍需点击“保存配置”才会生效。

## 能力与操作

助手可以查询平台资源、分析日志和状态、读取公开网页，并通过交互卡片收集配置、展示计划和反馈执行结果。持续运行的构建、发布等任务会显示真实状态；达到最终状态后，助手会继续检查结果。

交互卡片生成时会先在实际位置显示准备动画，校验完成后在同一位置替换为最终内容。若一轮回复只有一个必须先提交的配置表单，助手可以把它放在该轮回复末尾，便于阅读完说明后直接填写；候选列表、多张卡片、进度和结果仍按真实顺序显示。

配置表单中的密码和密钥字段可以直接填写，输入框会以密码形式显示。助手不会为这些字段预填默认值；只有你当次主动输入的非空值才会提交，留空表示不修改。提交工具动作时，密钥只会通过受控工具调用传递给平台，不会写入普通聊天消息或模型上下文；发送消息动作不会引用这些字段。

部署目标的运行时密钥必须通过安全表单提交。用户填写的 `values` 只进入 Direct Tool Action；需要随机凭据时由平台后端生成并直接保存，助手和浏览器不接收生成明文。清除凭据必须使用独立的明确清除操作，空输入不会清除现有值。普通环境变量由用户显式选择为 `public`，平台不会再根据字段名、URL 或内容推测敏感性并阻止保存；选择普通变量意味着该值不享受密钥的加密与不回显保证。审批摘要和执行结果只显示将设置、生成或清除哪些密钥字段及其状态，不会回显密钥明文。

助手根据当前回复生成的下一步选项会显示在对应回复气泡内，并保留它在消息、思考和工具调用之间的真实位置，便于判断选项来自哪段上下文。新会话尚未发送消息时，页面预设入口仍显示在输入框上方，方便直接开始常见任务。

高风险工具等待确认或 MFA 二次验证时，操作卡片会直接显示在工具行下方，无需先展开工具详情；工具参数、返回结果和调用标识仍保持折叠，可按需展开核对。

MFA 验证成功后，平台会签发一个只绑定当前用户、登录会话和操作用途的短期 Step-up 断言，并自动交给助手恢复当前工具调用。动态验证码具有防重放保护，恢复码也只能使用一次；正常情况下无需为同一次工具调用重复输入。如果验证成功后工具没有继续执行，请刷新会话确认当前状态，不要反复提交同一个验证码。

卡片按用途统一为五类：候选发现与比较（`candidates`）、结构化配置（`form`）、变更核对（`change_review`）、事实或执行结果（`result`）以及平台权威实时任务（`live_task`）。具体资源、诊断、图表和表格仍使用对应内容块呈现，不需要你理解或选择模板名称。

同一会话可以多次生成包含相同配置项的卡片。每张卡片的输入和选择彼此独立，操作当前卡片不会改变或跳转到较早的历史卡片。如果某一项生成内容暂时无法显示，助手只会在对应卡片位置显示降级提示，其他聊天记录和卡片仍可继续查看；刷新会话后还可以从已保存记录重新恢复。

平台工具较多时，助手只会使用经过审计且明确准入的能力；系统会结合当前目标评估相关工具，如果当前集合不足，会在当前对话轮内检索工具目录，再继续执行同一任务。工具检索不会绕过你的权限，也不代表业务操作已经执行，因此无需由用户记住或输入工具名称；管理员可在 Agent 可观测的工具详情中核对这次检索及其结果。

创建发布、构建或网关等异步资源时，助手会从平台返回的业务结果中取得真实资源 ID，再调用契约声明的详情工具回读状态；HTTP 请求被接受不等于任务已经成功。对近期刚得到空结果的相同只读查询，助手会直接说明未发现资源，避免在连续对话轮中重复读取；明确刷新实时状态时仍会重新观察。

根据仓库或官方部署文档交付应用时，助手会先评估项目官方维护的容器镜像。镜像版本、架构和拉取条件满足当前目标时，助手通常会建议直接使用镜像；无法验证、镜像不适用或你明确要求源码构建时，会改用源码构建流程。

当项目同时提供 Kubernetes/Helm 和 Docker/Compose 部署资料时，助手会优先采用与目标版本匹配的 Kubernetes/Helm 配置，并用 Docker/Compose 补充服务拓扑和运行参数。若 Kubernetes 资料过期、不完整或不适合当前环境，则会改用可验证的 Docker/Compose 或源码配置。

助手拥有与你相同的平台权限。你无法访问的项目空间或资源，助手也无法读取或操作。删除、发布、修改权限等高风险操作会先展示目标和参数，得到确认后才会执行；参数变化时需要重新确认。

查找项目空间时，助手默认只查询与你直接相关的项目。即使你是平台管理员，也只有在你明确要求“搜索全部项目空间”等全局范围时，助手才会查询平台上的全部项目空间。

诊断确实需要连续执行多条容器命令时，助手可以创建短期运行命令会话，保留工作目录和环境变量。每条命令仍会重新检查权限、项目开关、确认与 MFA；会话空闲或达到最长寿命后自动关闭，诊断结束时也会主动释放。不要把命令会话用作长期任务或密钥存储。

如果操作需要平台尚未提供的能力、额外权限或人工处理，助手会明确说明未完成的步骤。

## 页面上下文与隐私

助手会接收当前页面和已选资源等必要上下文，以便理解你正在处理的对象。密码、Token 和 Secret 不会作为页面上下文发送给模型，也不会进入交互卡片的消息记录。

助手读取外部网页时，不会携带你的登录 Cookie、Token 或 Git 凭据。私有仓库应先在平台中连接对应的 Git Provider。

工具详情会展示经过脱敏的参数、结果和排障标识。内部工具默认隐藏，平台管理员可在需要排查助手问题时开启调试模式。

## 常见问题

### 助手没有出现

请平台管理员确认助手已启用，并检查当前使用范围是否包含你的账号。助手入口只由平台启用状态和使用范围决定；Agent 或模型服务暂时不可达时，入口仍会保留，并在你发起操作时显示可重试的错误。

### 回复提示模型不可用

检查 Provider 服务状态、余额、模型目录中的模型名称和 API Key，然后重试。模型被停用后，已创建的 Run 仍使用自己的快照；新消息只能选择仍处于启用状态的模型。

如果 Agent 启动日志提示模型的 `maxContextTokens` 或 `maxOutputTokens` 缺失，请确认 Luna API 与 Agent 来自同一版本并一起升级；模型能力由 Luna API 根据模型目录统一下发，不需要在 Agent 容器中重复配置。

### 回复提示上下文或 Run 预算不足

上下文不足时，缩短当前输入、清理不需要的历史，或请管理员核对模型能力。Run 累计 Token/Credits 已耗尽时，新建任务后继续；个人钱包余额不足时，先充值或改用可负担的模型。这些情况下平台会在产生新的模型费用前停止调用。

### 工具执行失败

展开工具详情查看错误代码和请求编号。常见原因包括资源已经变化、账号权限不足、依赖服务不可用、参数格式错误或操作需要重新确认。

如果错误代码是 `ai.database_schema_mismatch`，请先启动或重启 Luna API，让它自动执行数据库迁移，再启动 Agent。Agent 不会自行修改数据库结构。托管模式首次启动必须从 Luna API 取得权威 Provider 与工具目录，无法取得时进程会退出；已经正常启动后，短暂的配置刷新失败会继续使用上一份有效配置。

如果错误代码是 `ai.final_response_missing`，表示模型只生成了工具或选项、没有给出可见结论，且在限定轮次内未自行补全；可以直接重试，或检查 Provider 是否稳定返回消息正文。

### 网页无法读取

目标可能被安全策略拦截、不是可读取的文本页面或暂时不可用。使用外网工具代理池时，还应确认至少一个代理可以连接。
