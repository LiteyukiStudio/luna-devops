# 首次登录

API 会在全新数据库首次启动时，根据部署配置创建首个管理员。平台不提供浏览器初始化入口，也不包含固定管理员账号或密码。

## 准备管理员配置

启动 API 前至少配置：

```dotenv
INITIAL_ADMIN_EMAIL=admin@example.com
INITIAL_ADMIN_PASSWORD=请替换为8至72字节的强密码
INITIAL_ADMIN_NAME=Platform Admin
INITIAL_ADMIN_LANGUAGE=zh-CN
```

名称可以留空并回退为邮箱；语言可以填写 `zh-CN` 或 `en-US`。密码应通过部署环境或 Kubernetes Secret 提供，不要写入仓库。

这组配置只在数据库中从未存在过用户时用于建号。已有有效平台管理员时，API 不会比较或覆盖其邮箱、名称、语言或密码；数据库已有用户但没有有效管理员时，API 会拒绝启动，需要先恢复已有管理员，避免配置意外创建第二个管理员。

## 登录

API 健康检查通过后访问：

```text
https://你的平台地址/login
```

使用部署配置中的邮箱和密码登录。后续修改管理员密码请在账号设置中完成，修改 `INITIAL_ADMIN_PASSWORD` 不会重置已有账号。

## 完成平台设置

首次登录后进入“全局设置”，至少检查：

1. 站点名称、公开访问地址和默认语言。
2. 注册策略与登录方式；内部平台通常关闭自由注册。
3. 邮件、OIDC、AI 助手和计费是否需要启用。
4. 数据保留、安全策略和管理员账号是否符合团队要求。
