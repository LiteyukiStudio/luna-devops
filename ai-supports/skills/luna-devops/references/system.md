# 系统管理

当前 `config` 与 `data-retention` 分类已进入目录。

## 全局配置

1. 读取配置定义与当前值。
2. 仅更新用户明确指定的键。
3. Secret 配置不回显；留空语义以 Help 为准。
4. 高风险配置更新受服务端计划协议门禁，遇到 `server_plan_required` 时停止。

## 数据保留

1. 读取支持的数据集目录。
2. 先按同一时间范围执行预览。
3. 展示数据集、时间范围和预计条数。
4. 用户确认后执行清理，并重新查询结果。
