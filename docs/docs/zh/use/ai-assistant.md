# AI 助手

AI 助手可以结合当前页面和你的平台权限，查询资源、解释状态并协助完成日常操作。

## 开始使用

平台管理员先在“全局设置 → AI 助手”中填写：

- Provider 地址
- API Key
- 默认模型
- 可选备用模型
- 允许使用助手的用户范围

保存并通过连接测试后，页面右下角会显示助手入口。

## 会话

打开助手后可以：

- 直接描述要查询或处理的问题
- 创建、切换、重命名和批量删除会话
- 在回复过程中切换到其他会话
- 随时中断仍在运行的回复

没有发送过消息的新会话不会重复保存。未手动命名的会话会根据话题自动命名；手动修改名称后，助手不会再覆盖它。

## 查询与操作

助手拥有与你相同的平台权限。你无法访问的项目空间或资源，助手也无法读取或操作。

普通查询会直接执行。删除、发布、修改权限等高风险操作会先显示确认卡片，你可以选择：

- 同意本次操作
- 拒绝
- 在当前会话中允许后续同类操作

确认不会扩大你的平台权限，后端仍会执行最终权限校验。

## 建议与页面跳转

回复完成后，如果模型生成了与当前任务直接相关且结构有效的下一步，助手会展示少量建议。建议可能用于：

- 继续追问或补充信息
- 打开相关平台页面
- 执行一个明确的后续操作

读取信息时，助手可能提供站内链接；需要你做选择时，会优先显示选项，而不是直接把你带离当前页面。
如果模型没有返回可靠的上下文建议，平台会直接省略建议区域，不会使用固定的通用选项补位。

## 页面上下文与隐私

助手会接收当前路由、页面类型和已选资源等结构化上下文，帮助理解你正在处理的对象。页面中的密码、Token 和 Secret 不会作为页面上下文发送给模型。

工具详情默认折叠。展开后可以查看经过脱敏的参数、执行状态和结果，便于确认助手实际做了什么。

## 常见问题

### 助手没有出现

请平台管理员确认 AI 助手已启用、Provider 连接测试通过，并且当前账号位于允许范围内。

### 回复提示模型不可用

检查 Provider 余额、模型名称和 API Key；如已配置备用模型，也可以切换后重试。

### 工具执行失败

展开工具详情查看错误信息和请求编号。常见原因包括资源已变化、当前账号没有权限、依赖服务不可用或操作需要再次确认。
