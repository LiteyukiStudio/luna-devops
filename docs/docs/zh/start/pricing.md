# 设置价格

平台管理员在“全局设置 → 计费配置”设置资源价格，在“全局设置 → AI 助手 → AI 模型目录”设置每个模型的 Token 价格。修改只影响之后产生的用量，历史记录继续使用产生时的价格快照。

## Credits 换算

账单以 Credits 结算。先选择展示货币，再设置“每 1 现实货币对应 Credits”。例如：

```text
货币：USD
1 USD = 100 Credits
```

该比例只负责账单展示换算，不会自动同步汇率。

## 平台资源价格

价格表按以下计量项配置：

| 资源 | 计量单位 |
| --- | --- |
| 构建 CPU | vCPU·分钟 |
| 构建内存 | GiB·分钟 |
| 运行 CPU | vCPU·小时 |
| 运行内存 | GiB·小时 |
| 持久化存储 | GiB·天 |
| 访问流量 | GiB |
| 数据卷传输 | GiB |
| 网关请求 | 1000 次 |

请根据实际云账单、包年资源、冗余成本和运维成本定价。默认值只是初始化参考，不代表市场承诺。

## AI 模型价格

模型目录分别保存普通输入、输出、缓存输入和缓存输出的每百万 Token 价格。平台使用 Provider 返回的实际用量结算，并由发起用户的个人钱包承担费用，不归集到项目空间。

表单可能为已收录模型显示建议价格；它只是录入辅助，不会随厂商调价自动更新。配置前应核对 Provider 当前价目和账号实际计费规则。

## 上线前检查

1. 使用一笔小额构建、运行和模型调用验证计量单位。
2. 核对账单展示货币、Credits 换算和四类 Token 价格。
3. 调价后确认新用量采用新价格、历史账单保持不变。
4. 不需要计费的项目可将对应计量项设为 `0`，并确认产品页面的展示符合预期。
