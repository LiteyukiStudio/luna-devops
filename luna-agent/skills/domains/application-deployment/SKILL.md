# 应用、部署与发布工作流

## 适用范围

处理应用 CRUD、应用市场模板（单组件与多组件）检索安装、部署目标（Deployment/StatefulSet）配置、运行配置集与运行时密钥、创建发布、回滚、取消发布及副本扩缩容。

## 标准工作流

1. **定位三元组**：操作部署与发布前先解析真实 `projectId`、`applicationId` 与部署目标 `targetId`（及对应 `stage`、有效运行集群和当前镜像）。`clusterId` 为空代表使用平台默认集群，仅在存在多个可用集群且需用户决策时才请求选择。
2. **应用市场两阶段安装**：
   - 先按关键词或分类检索模板摘要，选定真实 `templateId` 后再读取模板详情参数。
   - 区分单组件模板（使用 `projectVolumeId` 等顶层参数）与多组件模板（`components` 非空，按组件 `key` 绑定独立数据卷，不混传单组件覆盖字段）。
   - `stage=prod` 的模板安装与所有部署目标修改、重启、发布、回滚、取消发布均受 `L2` 逐次参数绑定审批保护。
3. **停机、扩缩容与发布边界**：
   - 停止现有工作负载通过更新部署目标将 `replicas` 设为 `0`（恢复时改回正整数），该操作直接作用于工作负载而不创建新 Release。
   - CPU/内存指标自动扩缩容（HPA）的最小副本数必须 `>= 1`，不能用于从零副本自动唤醒。
   - 取消正在执行的发布不会自动回滚已下发到集群的资源，需回读工作负载与最新 Release 状态确认实际影响。
4. **运行时配置与密钥隔离**：普通环境变量声明公开模式；运行时密钥只能通过专用运行时密钥工具使用 `set` / `generate` / `clear` 处理，不在普通环境变量或卡片默认值中传递明文。
5. **异步发布收口**：单步创建发布或回滚返回受理状态后，使用 `present_card`（`template: live_task`，绑定 `release`）展示实时进度并结束本轮；仅在用户明确要求等待发布终态继续后续动作时调用 `wait_for_task`。
