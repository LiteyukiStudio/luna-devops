# 默认定价与建议价格

平台默认的计费单价是**参考值**，不是市场承诺价格。管理员可以按自己的集群成本、云服务商账单和运营成本随时调整：资源价格在「全局设置 → 计费配置」的价格表中修改，AI 模型 Token 价格在「全局设置 → AI 助手」的模型目录中按模型维护。修改只影响之后产生的用量。

## 换算口径

- 平台结算单位是 Credits，参考换算：**1 美元 = 100 Credits**。
- 当管理员在「计费配置」中把现实货币单位设为 USD、「每 1 现实货币对应 Credits」设为 100 时，账单概览的折算金额与本文美元参考价一致；使用其他货币时按实际汇率调整该比例。
- AI 模型建议价格 = 厂商官方美元刊例价（每 100 万 Token）× 100。

## 平台资源默认价格

内置默认单价参考主流公有云（AWS、阿里云、腾讯云、GCP 等）的计算、存储与流量刊例价取整得到，对应一台中等规格按需实例的大致成本：

| 计费项 | 默认单价（Credits） | 计量单位 | 参考依据 |
| --- | --- | --- | --- |
| 构建 CPU | 10 | vCPU·分钟 | 按需 vCPU 约 $0.03–0.05/小时 |
| 构建内存 | 2 | GiB·分钟 | 按需内存约 $0.004–0.007/GiB·小时 |
| 运行 CPU | 30 | vCPU·小时 | 同上，运行实例按整小时窗口结算 |
| 运行内存 | 6 | GiB·小时 | 同上 |
| 持久化存储 | 1 | GiB·天 | 云盘约 $0.10–0.17/GiB·月 |
| 访问流量（出站） | 1 | GiB | 公网出站流量约 $0.08–0.12/GiB |
| 数据卷传输 | 0（默认停用） | GiB | 默认免费，可按需启用 |
| 网关请求数 | 0（默认停用） | 1000 次 | 默认免费，可按需启用 |

如果你自建集群或有包年包月折扣，通常可以把计算类单价下调；如果希望覆盖运维成本，可以适当上浮。
