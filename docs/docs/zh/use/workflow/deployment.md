# 创建部署配置

部署配置描述应用**从哪里来、运行在哪里、如何运行**。一个应用的每个阶段只能有一份部署配置。

## 必填内容

- 阶段：`dev`、`test`、`staging` 或 `prod`，创建后不可修改。
- 目标运行集群。
- 来源：已有镜像或源码仓库。
- 容器端口、CPU、内存和副本数。
- 镜像拉取策略与必要的健康检查。

## 选择来源

**已有镜像**适合最快上线。填写完整镜像地址，确认目标集群拥有拉取权限，然后保存并创建 Release。

**源码仓库**需要先绑定仓库、选择分支和 Dockerfile，再选择拥有推送凭据的镜像站。保存后先执行构建，成功后再发布生成的镜像。

只有应用确实需要时，再展开高级配置添加启动命令、自动伸缩、StatefulSet、调度规则、安全上下文、辅助容器或部署 Hook。

修改镜像、资源、Service、数据卷或高级运行配置后，需要创建新 Release 才会影响当前实例。页面出现“保存并重新部署”时，应在确认影响后使用该操作。
