# 选项与工作流连续性

## 选择卡片或快捷选项

- 先按根 Skill 直接索引的 `resource-resolution.md` 解析资源候选。有效候选只有一个时直接
  采用并继续，不生成卡片或快捷选项；以下规则只处理仍然存在的真实选择。
- 用卡片或快捷选项让用户从已有资源中选择时，只要平台支持创建该资源，就额外提供一个
  “新建”入口（卡片的 `groupActions`），用户选择后进入创建流程并在完成后回到原工作流；不得只给现有候选。
  具体规则见根 Skill 直接索引的 `resource-resolution.md`。
- 真实资源单选使用 `request_choice`，结构化参数使用 `request_input`；诊断、健康、进度和终态结果使用 `present_card`。
- 每个卡片工具单次提交完整输入；Agent 在调用开始时签发生成标识并创建占位，校验通过后客户端在同一位置显示最终内容。模型不要提供或维护 `generationId`。
- 简单追问、单一步骤建议或无需结构化交互的动作直接写入回复；只有确实需要用户选择少量可信候选时才调用 `request_choice`。
- 需要用户填写文本、数值、布尔值、枚举或多字段配置时使用 `request_input`；只需从少量真实资源候选中单选时使用 `request_choice`，不得用快捷选项代替输入控件。
- 同一个最终回复只选择一种，不重复呈现相同动作。

## 组织有用选项

- 生成 2-5 个不同选项，按预期收益排序。
- 仅当本轮回复确实存在清晰、可独立点选的下一步时，独立预测阶段才生成一次快捷选项；任务正在等待表单提交、被批准阻塞、或没有下一步时不生成。主任务模型只需准确完成回复，不得停下来等待快捷选项。
- 选项应对应下一个未解决步骤，而不是附近页面。
- 使用能描述选择结果的单行短标签。中文通常不超过 18 个字，其他语言不超过 32 个字符；
  不写句号、说明、序号或每项都重复的前缀。快捷栏不展示 description，无必要时不要生成。
- 名称可能重复时，在 `send_message` 值中包含可信资源 ID。
- 候选超过五个时，提供最相关候选，并增加搜索、筛选或查看更多的选项。
- 不得展示不可用、未授权或虚构的操作。

## 引导不了解平台的用户

当用户没有明确任务，并询问助手能力、使用方法、起步方式或自己应该做什么时：

1. 用一两句话说明助手会结合当前页面和用户权限协助查询或操作。
2. 在回复中给出 2～5 个具体目标；只有用户必须先选择一个目标才能继续时，才调用一次 `request_choice`。
3. 优先使用 `send_message`，让点击结果成为明确的新任务。选项应描述用户结果，例如“部署一个应用”“排查构建失败”“查看运行状态”，而不是内部模块名。
4. 当前页面已经提供明确场景时，优先给出该场景的常用目标；看板等通用页面可以覆盖交付、诊断、资源查看和平台配置。
5. 不得根据未验证信息假定用户拥有某个项目空间、应用或管理员权限；需要具体资源时，在用户选择目标后再调用读取工具发现。

如果用户已经提出明确任务，应直接完成该任务，不要退回通用新手菜单。

当用户选择或说出“部署一个应用/我的项目/网站”且表现出不熟悉部署（“第一次”“不会”“不懂”）时，
先用通俗语言确认代码仓库或镜像、目标项目空间和期望访问方式。能从仓库与平台工具发现的构建方式、
启动命令和端口不要反问；只有证据冲突或必填值无法发现时才用表单收集，然后进入交付 reference。

## 按工作流阶段选择

| 阶段 | 首选动作 |
| --- | --- |
| 同类有效资源只有一个且符合当前任务 | 自动采用并继续，不创建选择交互 |
| 选择项目空间、应用、集群、环境、代码仓库、镜像、发布、域名或其他目标 | `send_message` |
| 从已发现的可信候选中做无需额外输入的单击选择 | `send_message` |
| 补充名称、标识符、分支、Tag、端口、主机名、限制、策略或其他结构化参数 | `form` |
| 执行参数完整的已注册操作 | `request_tool` |
| 检查已知结果或资源页面 | `navigate` |
| 调查错误或比较方案 | `send_message` 或已注册读取工具 |

选择目标不会执行操作。目标拥有页面 URL，也不代表该选择应变成跳转。

只要某个选项点击后仍要求用户手动编辑消息、替换占位符或继续输入参数，该选项就不适合成为快捷选项，应改为表单卡片。

## 从表单继续会话

- 仅收集或确认配置时，使用 `send_message` 动作把非敏感字段带回下一轮。
- 消息中的字段引用只写成 `{{field_id}}`，例如
  `继续检查实例 {{instance_name}}，镜像为 {{image_tag}}`。
- 字段 ID 必须存在于同一卡片；不要引用其他卡片、隐藏的未知值或不存在的路径。
- 密码、令牌、Secret 和秘密键值不得插入消息。需要执行时，改由已注册工具动作的
  受控参数绑定处理。
- 含必填字段的继续动作应等待字段通过校验后再允许触发。

## 保持独立性与可重复性

- 每个选项都应可独立选择。
- 跳转是幂等的，可以重复执行。
- 消息和操作请求会创建新工作，只能成功一次。
- 跳转成功不得禁用同级消息选项。
- 非幂等操作选择后必须禁用，不得执行两次。

## 从失败中恢复

- 校验错误：说明无效或缺失字段，并提供修正值。
- 权限错误：说明当前登录用户缺少所需权限；有帮助时提供只读替代方案或管理员处理路径。
- 未找到：验证可信目标，或提供搜索或列表操作。
- 冲突：说明冲突状态，并提供刷新、检查或安全解决方案。
- 瞬时依赖失败：提供重试和状态检查。
- 未知内部失败：提供安全稳定的消息，以及可用的 Trace 或请求标识；不得猜测原因。

除非第二条消息增加了具体恢复操作，否则不要同时在工具内容和独立助手提示中重复同一错误。
