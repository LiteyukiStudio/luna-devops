# AI 助手

AI 助手可以结合当前页面和你的权限，查询资源、解释状态、分析日志，并协助完成部署和日常运维。

## 可以做什么

- 查找项目空间、应用、构建、Release、集群和访问入口。
- 分析失败状态并给出可验证的排查步骤。
- 根据仓库、现有镜像或应用市场模板准备部署。
- 通过表单收集参数，在确认后执行平台操作。
- 依据与当前平台版本一致的公开文档，解答概念、操作步骤、配置语法、模板变量和限制等问题，并注明出处。

直接描述目标即可，例如“检查这个应用为什么无法访问”或“用这个仓库部署 API”。不熟悉容器或 Kubernetes 时，可以说明“第一次部署”，助手会按步骤解释必要概念。

## 执行权限模式

输入框底部支持按当前会话随时切换四档执行权限模式（每次新建会话默认回到**默认**模式）：

| 模式 | 适用场景 | 审批与执行行为 |
| --- | --- | --- |
| **严格审批**（`strict`） | 关键变更核对 | 所有写操作每次都需人工批准，不启用本会话记忆。 |
| **默认**（`default`） | 日常巡检与协作 | 只读工具自动执行；常规可逆写操作支持“批准并在本会话记住”；部署、路由、删除、密钥与生产环境变更逐次预览并等待批准。 |
| **自动**（`auto`） | 测试/预发连续构建部署 | 自动预检并执行非生产环境的构建、配置、发布与访问入口变更；仅对删除/移除/解绑/吊销、生产环境（`prod` / `production`）、容器远程命令及平台级管理配置保留人工批准。 |
| **完全访问**（`full_access`） | 受控全自动交付 | 自动放行当前账号权限与会话项目沙箱内的全部操作（含高危操作与生产环境变更），输入框底部会高亮提示。 |

> 即使开启**自动**或**完全访问**模式，后端仍强制执行登录会话校验、项目与平台 RBAC、单项目会话沙箱、L2 变更预检锁（冲突拦截）与完整危险操作审计日志。若会话正停在“等待批准”步骤，将模式切换为覆盖该操作的**自动**或**完全访问**后会立即自动继续执行。

## 能力边界

> AI 助手是操作入口和诊断助手，不是权限绕过工具，也不能替代上线前的人工验收。

- 助手只能访问你本来有权访问的资源。
- 默认模式下，删除、发布、权限变更等高风险操作会展示目标和参数并等待确认；参数变化后需要重新确认。
- 构建、发布等异步操作只有在权威状态进入终态后才算完成。
- 外部服务不可用、权限不足或平台缺少能力时，助手会说明未完成步骤，不会把受理请求报告为成功。
- AI 可能理解错误。执行变更前应核对资源、环境、镜像版本和影响范围。

## 信息安全

- 页面上下文不会包含密码、Token 或 Secret 明文。
- 密钥通过受控表单和工具直接交给平台，不写入普通聊天消息；保存后不回显。
- 读取公开网页时不会携带浏览器 Cookie、登录 Session、Token 或 Git 凭据。私有仓库应先连接 Git Provider。
- 不要在对话中粘贴私钥、生产数据库密码、完整 kubeconfig 或其他长期凭据。
- 工具详情和诊断结果可能包含资源名、日志和配置片段，应按内部运维数据管理。

## 开始使用

平台管理员需要先在“全局设置 → AI 助手”配置兼容 OpenAI `chat/completions` 的 Provider、可用模型、访问范围和个人钱包计费。启用后，顶栏右上角会出现“Luna AI”按钮。

桌面设备会在工作区右侧打开停靠面板，再次点击按钮或关闭面板即可收起；点击面板头部的“展开为全屏”进入完整的助手页面。手机、窄屏设备和触控设备会直接进入完整的助手页面。移动端的会话列表同样使用完整页面，返回时先回到对话，再回到进入助手前的工作区。进入移动页面时不会自动呼出键盘；点击输入框后再开始输入，键盘打开期间输入区会保持可见。

通过 New API 等兼容网关接入多个上游渠道时，可参考[渠道亲和性与 Prompt 缓存键配置](/reference/channel-affinity)，显式选择被网关隐藏的 Provider 兼容类型，并让同一会话尽量复用相同渠道。未知兼容端点默认不会收到 `prompt_cache_key`，只有确认整条请求链支持后才应启用。

如果入口不存在，请联系管理员确认功能和账号范围；如果模型暂时不可用，保留当前会话并稍后重试。若希望从 Claude Code、Cursor、Antigravity 等外部 IDE 或终端 Agent 直接操作平台（包括未开启网页内置 AI 助手的自托管实例），请查看 [MCP 接入](/use/mcp)。

正在输出时刷新页面或重新打开助手，页面会先回读已确认的时间线，再从最近事件位置继续接收当前 Run；
连接仍在建立或短暂停滞时会保留正在输出提示。若连接超过恢复窗口仍不可用，最终以服务端返回的完成、
失败、取消或中断状态为准，不把未确认的局部文本当作完成结果。

输入框旁的上下文比例使用当前模型最近一次主回答完成后的官方 `total_tokens` 和当时的模型窗口快照。发送下一条消息后，页面会沿用这份会话级已确认值，不会在排队或输出期间清零；新结果返回后再替换为最新值，因此上下文通常随对话增长，并会在上下文压缩后按真实结果下降。该数值不是把历次请求用量相加。尚未发起模型调用的新会话显示 0%；Provider 从未返回可验证用量或已切换模型时，页面只显示灰色圆环，悬停或键盘聚焦后提示“暂无 Provider 用量数据”。
