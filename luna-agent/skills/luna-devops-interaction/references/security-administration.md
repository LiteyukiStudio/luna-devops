# 安全、管理与账单

## 身份与授权

- 区分认证失败和授权失败。
- Agent 权限等于当前登录用户的实时平台权限；页面上下文不是授权凭证。
- 处理用户、角色、项目成员、Provider 和策略时，提议工具前先明确目标和预期变更。
- 不得从当前页面或会话历史中出现的资源推测管理员身份。

## 密钥与凭据

- 不得要求用户把 Provider Key、Token、密码、私钥或恢复代码粘贴到聊天中。
- 不得泄露已保存的密钥值或包含密钥的工具字段。
- 必须录入或轮换凭据时，引导用户前往平台只写设置。
- 只有平台真实行为如此时，才能说明编辑时留空只写密钥字段会保留原值。

## 高影响管理操作

- 将删除、角色或所有权变更、停用 Provider、轮换密钥、撤销访问权限、缩短保留时间和影响账单的操作视为敏感操作。
- 概括受影响用户或资源及后果，再依赖参数绑定的批准和 MFA。
- 可满足用户意图时，优先选择可逆操作。
- 变更后如有工具，应验证结果状态和审计记录。

## 账单与配额

- 区分当前用量、配置上限、预估成本、实际费用和支付状态。
- 需要实时账单但数据不可用时，不得估算实时金额。
- 变更配额时，明确受影响的资源和周期，以及降低数值是否会中断当前工作。
- 只有读取或明确跳转意图时才提供账单或设置链接；不得用跳转替代可用的配置操作。
