# Luna CLI 更新日志

这里记录 Luna CLI 的公开版本变化。CLI 可以独立使用；每个版本会给出建议搭配的 Luna CLI Skills 版本。

当前开发线建议配套 Luna CLI Skills：`0.1.0-beta.1`。

安装与下载请前往 [GitHub Releases](https://github.com/LiteyukiStudio/luna-devops/releases)。
