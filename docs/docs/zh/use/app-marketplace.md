# 应用市场

应用市场提供经过整理的安装模板，并按数据库、存储、监控观测、开发工具、协作与内容、中间件和安全工具七类组织，方便快速找到常用自托管应用。

## 安装应用

1. 搜索或筛选模板，并先阅读用途、前置条件和参数说明。
2. 选择“安装”，指定项目空间和运行集群。
3. 确认应用名称、镜像、资源规格，并选择已有数据卷或直接创建空白卷。
4. 填写必要参数；支持平台生成的密码可以留空。
5. 选择是否立即部署并确认安装。

模板会创建应用和部署配置，并按选择创建首个 Release。Secret 参数只写入密钥存储，不会在页面或安装结果中回显。

Redis 模板的密码是可选项。建议填写较长的随机密码；留空时 Redis 会在不启用密码认证的情况下运行。填写的密码只通过 Secret 注入运行环境，密码明文不会写入普通环境变量或安装参数快照。

安装完成后检查 Release、工作负载、日志和访问方式。模板不会替你完成第三方应用内部配置，例如 Grafana 数据源、数据库业务账号或外部 OAuth。

部署阶段只接受 `dev`、`test`、`staging` 或 `prod`。CLI 使用稳定命令 `luna app-template install`；Agent 与 CLI 会在请求发出前拒绝 `default`、`qa` 等非法值，并返回允许值。平台兜底校验返回 `deployment.stage_invalid`、字段路径和 `retryable: false`；自动化调用方必须修正参数，不能原样重试。

## 数据卷

需要持久数据的模板会要求选择同项目空间、同集群且卷模式匹配的数据卷。安装弹窗可以直接为当前运行集群创建符合模板卷模式的空白卷，创建受理后会自动选中；也可以选择已经存在的兼容卷。若创建任务暂时无法投递，弹窗会保留输入，直接重试会继续同一次创建而不会生成重复数据卷。未选择真实数据卷时不会自动降级为 `emptyDir`。其他创建与接入方式见[运行数据持久化](./workflow/runtime-data-persistence)。

## 平台组件

带“平台组件”标识的模板只允许平台管理员安装，用于给指定运行集群补充平台能力，例如网关流量采集。平台组件也以普通应用运行，可以在应用和部署页面查看状态、修改允许的配置并重新部署。

> 模板是可检查的起点，不保证适合所有生产环境。安装前仍需核对镜像版本、架构、资源、存储和外部依赖。
