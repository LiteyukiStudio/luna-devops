# 初始化平台

平台启动后，先创建首个管理员，再完成平台级基础设置。

## 创建首个管理员

生产部署不会创建固定管理员。访问：

```text
https://你的平台地址/bootstrap
```

输入部署时设置的 `BOOTSTRAP_TOKEN`，创建管理员账号。成功后请立即从部署配置或 Secret 管理系统中**移除或轮换该一次性凭据**。

> `/bootstrap` 只用于首次初始化。之后应使用本地账号或管理员配置的 OIDC 身份源登录。

## 完成平台设置

登录后进入“全局设置”，至少检查：

1. 站点名称、公开访问地址和默认语言。
2. 注册策略与登录方式；内部平台通常关闭自由注册。
3. 邮件、OIDC、AI 助手和计费是否需要启用。
4. 数据保留、安全策略和管理员账号是否符合团队要求。

## 创建项目空间

项目空间提供逻辑隔离，用于归集同一产品或团队的应用、成员和资源。可以先创建一个测试项目空间，后续再按最小权限添加成员。

接下来进入[添加基础资源](./connect-resources)，为用户准备集群、镜像站和 Git Provider OAuth。
