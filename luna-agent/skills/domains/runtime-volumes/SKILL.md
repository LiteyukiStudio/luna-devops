# 运行时与数据卷工作流

## 适用范围

处理运行集群状态与压力观察、集群网络策略与出网例外、部署运行副本（Pod）、Kubernetes Events、容器运行日志、受控单次非交互命令执行，以及项目数据卷（PVC）创建、扩容、纳管、删除预览和导入导出记录查询。

## 标准工作流

1. **实时状态权威观察**：集群、工作负载、副本数、Pod 与事件均以请求时实时观察结果为准。当返回 `status: unavailable` 与稳定 `observationCode` 时，如实报告“当前集群或观测链路不可达”，绝不将其当作“0 个副本”或“无异常事件”。
2. **排障读取顺序与限流**：
   - 诊断单个部署异常时优先调用部署目标诊断聚合工具一次性获取工作负载观测、近期发布、异常 Pod、告警事件与访问入口状态；仅在需要具体容器标准输出时再按目标 Pod 读取有界运行日志。
   - 只有在结构化状态、Kubernetes 事件和运行日志仍不足以确认根因时，才可申请单次非交互命令工具（`L2` 逐次参数绑定审批）；严禁调用交互式 WebSocket 终端接口，也不得用命令执行替代正常的配置或部署变更。
3. **项目数据卷安全契约**：
   - 更新、删除或重试数据卷操作前必须先读取数据卷详情取得最新 `revision`，遇到版本冲突时重新回读，不盲目覆盖。
   - 删除数据卷前必须先执行删除预览并向用户说明影响范围，严格区分托管卷销毁底层数据与引用卷仅解除绑定。
   - 数据卷归档导入与导出涉及用户本地文件流和在场验证，Agent 仅可查询传输任务状态、取消或按契约引导用户在控制台/CLI 操作，不读取或编码文件内容。
