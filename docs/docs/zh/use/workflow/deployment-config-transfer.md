# 导入与导出部署配置

部署配置可以导出为 JSON，再导入另一个应用。**导入只创建新配置，不会覆盖现有配置，也不会自动构建或发布。**

## 导出

在应用“部署”页打开目标配置的操作菜单，选择“导出 JSON”。文件包含运行规格、构建设置、发布策略和非敏感配置，不包含凭据、Secret 明文、运行状态或历史记录。

即使不含 Secret，文件仍可能包含镜像地址和普通配置，请按内部配置资料管理。

## 导入

1. 在目标应用的“部署”页选择“导入 JSON”。
2. 选择文件，并确认名称、阶段和命名空间。
3. 按预检结果映射仓库、镜像站、集群、变量集、Hook 和项目数据卷。
4. 重新填写需要的 Secret。
5. 预检显示“可以导入”后提交。

公开阶段只允许 `dev`、`test`、`staging` 和 `prod`；`production` 会转换为 `prod`。同一应用中阶段必须唯一。

数据卷映射只建立挂载关系，不复制 PVC 或数据。需要迁移运行数据时，先使用[运行数据持久化](./runtime-data-persistence)中的导入与导出功能。

导入完成后检查镜像、仓库、集群和运行配置，再手动构建或发布。
