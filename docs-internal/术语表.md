# 用户可见术语表

控制台文案、公开文档和 Agent 面向用户的回复统一使用下表术语。新增或修改文案时先查本表；需要新增术语时
同时补充本表与 5 种语言（`web/src/i18n/locales/{zh-CN,zh-TW,en-US,ja-JP,ko-KR}`）。代码标识、API 字段、
Tab key 与 URL 参数不随术语调整改名，避免破坏契约和已分享链接。

## 核心对象

| 对象（代码/API） | zh-CN | zh-TW | en-US | ja-JP | ko-KR | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `GatewayRoute` / HTTPRoute | 访问入口 | 訪問入口 | Access route | アクセスエントリ | 접근 진입점 | 把域名和路径转发到部署配置的服务端口。表单或说明需要强调域名时写“访问入口（域名）”；`host` 字段本身仍叫“域名”。 |
| `RepositoryBinding` 与 Git 仓库 | 代码仓库 | 程式碼倉庫 | Code repository | コードリポジトリ | 코드 리포지토리 | 应用绑定的源码仓库。“绑定 / 解绑代码仓库”描述绑定关系，解绑不会删除 Git 平台上的仓库。 |
| `/code-repositories` 页面（Git Provider + Git 凭据） | 代码仓库 | 程式碼倉庫 | Code Repositories | コードリポジトリ | 코드 리포지토리 | 导航名；页面内再分“Git Provider”“Git 凭据”。不再使用“代码库”“代码源”。 |
| `DeploymentTarget` | 部署配置 | 部署配置 | Deploy config | デプロイ設定 | 배포 구성 | 保持不变。 |
| `BuildRun` | 构建 | 構建 | Build | ビルド | 빌드 | 保持不变。 |
| `Release` | 发布 | 釋出 | Release | リリース | 릴리스 | 保持不变。 |
| 项目空间级 `RuntimeConfigSet` | 运行配置 | 執行配置 | Runtime config | 実行設定 | 실행 설정 | 在“共享配置”分区内的 Tab 名；部署配置编辑页中引用它时写“共享运行配置”。 |
| 项目空间级构建变量集 | 构建变量 | 構建變數 | Build variables | ビルド変数 | 빌드 변수 | 位于“共享配置”分区。 |
| 项目空间级 Hook 脚本 | 钩子 | 鉤子 | Hooks | フック | 훅 | 位于“共享配置”分区；部署配置中的绑定仍称“部署 Hook”。 |

“网关”只用于平台管理员视角的集群级 Gateway / GatewayClass / listener 配置和 Kubernetes 资源类型，不再作为
用户对象名（不用“域名路由”“网关路由”“高级网关配置”）。访问入口表单内的两组字段称“基础配置”“高级配置”。
账单中的“访问”分组表示访问入口产生的流量费用，属于费用分类名，不是对象名。

## 导航结构

- 应用详情 Tab 与核心交付路径一致：概览 → 构建 → 部署 → 访问入口 → 拓扑 → 设置。Tab key
  （`overview/builds/deployments/gateway/topology/settings`，旧 `repositories` 归入 `settings`）保持不变。
  概览只放上线引导、事实条和最近活动；各部署配置明细只在“部署”Tab。
- 绑定或切换代码仓库的入口是部署配置编辑页“基本信息与来源”中的代码仓库字段；应用“设置”Tab 只查看、
  维护和解绑已绑定的代码仓库。
- 项目空间侧栏分区：概览（默认落地页）→ 应用 → 共享配置 → 数据卷 → 成员 → 服务关系。
  “共享配置”内用 Tab 切换构建变量 / 运行配置 / 钩子，URL 为 `?tab=shared-config&config=<build-variables|runtime-configs|hooks>`；
  旧链接 `?tab=build-variables|runtime-configs|hooks` 由前端重定向到对应 Tab。分区定义只维护在
  `web/src/pages/projects/overview/project-workspace-sections.ts`。
