# 应用市场

应用市场提供数据库、缓存、监控工具和常用自托管应用的安装模板，适合不想从空白配置应用的场景。

安装模板通常会创建一个应用、镜像来源的部署配置、所需配置和数据卷，并可立即创建首个 Release。密钥类参数只会写入平台密钥存储，不会在页面中回显。

## 安装步骤

1. 进入“应用市场”，搜索或筛选需要的模板。
2. 点击“安装”，选择项目空间和运行集群。
3. 确认应用名称、镜像、资源规格和数据容量。
4. 填写模板要求的参数；支持自动生成的密码可以留空。
5. 选择是否立即部署，然后确认安装。

模板目录只加载用于检索和比较的摘要；选择模板后才读取完整安装参数。Secret 参数不会携带默认明文，搜索无匹配时会显示空结果而不是执行失败。

安装完成后，平台会打开新应用的部署页。请检查 Release 和工作负载状态，确认应用已经正常运行。

## 平台组件

带有“平台组件”标识的模板仅限平台管理员安装。它们用于为指定运行集群补充平台能力，例如访问流量采集，并由平台统一管理。

平台组件未安装、尚未产生有效数据或运行集群不可用时，相关页面会显示对应状态和处理入口。

## 使用限制

模板适合可以通过默认镜像命令启动的应用。部分应用仍需要已有数据库、外部服务或额外初始化步骤，请在安装前查看模板说明和项目官方文档。

安装模板不会自动完成第三方应用之间的集成。例如独立安装 Prometheus 和 Grafana 后，仍需按实际环境配置数据源和采集目标。
