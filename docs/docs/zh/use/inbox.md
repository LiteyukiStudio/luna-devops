# 消息盒子

消息盒子集中展示与你相关的平台消息和待处理请求。你可以查看未读消息、打开关联资源、归档消息，或处理需要确认的请求。

## 处理请求

在“待处理”中打开请求，核对发起人、项目空间和操作影响，然后接受或拒绝。请求处理后不能重复操作；已经过期或资源状态发生变化时，需要重新发起。

费用归属转移会让项目空间之后产生的费用由你的账号承担，历史费用不会迁移。不希望承担后续费用时，请拒绝请求。接受时平台会重新校验当前登录会话和相关权限。

## 与外部通知的区别

消息盒子用于在平台内阅读和处理与你相关的信息；[通知](./notifications.md)用于按规则把平台事件发送到邮箱、Webhook 或协作工具。两者可以同时使用。
