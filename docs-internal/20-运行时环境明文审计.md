# 运行时环境明文审计

本页用于检查结构化 `public` / `secret` 契约启用前已经写入普通配置列的数据。审计只读，不会自动迁移或删除任何记录，因为系统无法仅凭键名可靠判断历史值是否确属密钥。

## 执行审计

在已配置数据库连接的受控管理终端执行：

```bash
go run ./cmd/audit-runtime-environment --acknowledge-sensitive-metadata
```

建议先限定一个项目空间：

```bash
go run ./cmd/audit-runtime-environment \
  --acknowledge-sensitive-metadata \
  --project-id prj_example
```

输出只包含资源类型、资源 ID、项目空间 ID 和疑似敏感键名，不包含普通值、密钥明文、Secret 引用或请求正文。命令要求显式确认元数据输出，错误日志也不会写出原始列内容。

## 人工处置

1. 由项目空间管理员确认每个键是否确属密钥。
2. 若是密钥，先从普通配置中移除该键并保存。
3. 再通过部署目标或运行配置集的“运行时密钥”安全入口写入新值。
4. 创建新 Release，并从权威运行时配置回读确认该键只来自 Secret。
5. 轮换可能已经以明文保存或暴露过的凭据。

不要直接复制历史普通列中的疑似密钥完成迁移；平台不会读取并回显该值。无法确认时保留记录并升级给安全负责人，不要自动删除。
