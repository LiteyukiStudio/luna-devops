# 第一次进入控制台

平台启动后，先完成管理员初始化并创建第一个项目空间。外部系统可以稍后按需连接。

## 登录或初始化

完整部署默认不会创建固定管理员。第一次进入时访问：

```text
http://localhost:8088/bootstrap
```

输入部署环境中的 `BOOTSTRAP_TOKEN`，创建第一个管理员账号。完成后请从部署配置或 Secret 管理系统中移除或轮换这项一次性凭据。

后续可以使用本地账号或管理员配置的 OIDC 身份源登录。只在可信设备上启用“保持登录”；修改密码、账号权限或登录方式后，平台可能要求重新登录以保护账号安全。

## 看板

登录后的看板会汇总正在进行的构建和发布、需要处理的失败任务、近期活动以及集群和镜像站准备情况。可以从异常项直接进入对应资源处理问题。

## 创建第一个项目空间

项目空间用于组织同一个产品或团队的应用、成员和运行配置。进入“项目空间”并创建一个空间：

| 字段 | 建议 |
| --- | --- |
| 名称 | 使用产品名或团队名 |
| 标识 | 使用英文小写和短横线 |
| 成员 | 首次使用时先保留自己 |

## 创建第一个应用

一个应用对应一个可独立部署的服务。填写名称和标识即可；标识创建后不能修改。镜像、端口、环境变量和数据卷在部署配置中设置。

## 下一步

继续 [连接集群和镜像站](/start/connect-resources)。已有镜像时，优先从镜像部署以快速验证平台；需要从源码构建时，再连接 Git Provider 并配置构建参数。
