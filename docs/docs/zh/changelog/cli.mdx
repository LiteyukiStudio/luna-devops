# Luna CLI 更新日志

> `0.0.12` 及更早版本发布在 Luna DevOps 旧仓库中，以下历史链接保持不变。
> 后续版本请前往独立的
> [Luna CLI Releases](https://github.com/LiteyukiStudio/luna-cli/releases)。

这里记录 Luna CLI 的公开版本变化。CLI 可以独立使用；新版本会在同一个 Release 中强制附带完全同版本的 Luna DevOps Skill。

当前开发线采用 CLI 与 Skill 同版本、同 tag、同 Release 的绑定策略。每个版本只发布一个 `luna-devops` Skill，由根 `SKILL.md` 将任务路由到 `references/` 中按需加载的领域说明。

新的 CLI 安装包、二进制文件和配套 `luna-devops-<version>.skill` 均可从 [Luna CLI Releases](https://github.com/LiteyukiStudio/luna-cli/releases) 获取；以下旧版本链接仅用于历史追溯。

## 0.0.12

发布日期：2026-07-27

[GitHub Release](https://github.com/LiteyukiStudio/luna-devops/releases/tag/cli-v0.0.12) · [查看版本代码](https://github.com/LiteyukiStudio/luna-devops/tree/cli-v0.0.12)

**配套关系：** Luna CLI 与 Luna DevOps Skill 均为 `0.0.12`，必须精确同版本使用。

**安装此版本**

<Tabs groupId="cli-release-install">
  <Tab label="AI 安装 Skill" value="ai">

```text
请使用当前 AI 环境支持的 Skill 安装机制，为我安装与 Luna CLI 0.0.12 精确配套的 Luna DevOps Skill。
1. 打开 GitHub Release：https://github.com/LiteyukiStudio/luna-devops/releases/tag/cli-v0.0.12
2. 查找并下载 luna-devops-0.0.12.skill，同时使用同一 Release 中的 SHA256SUMS 校验文件。
3. 安装后读取 Skill 根目录的 SKILL.md，并运行 luna --version，确认 CLI 版本也是 0.0.12。
4. 如果该历史 Release 没有同版本 Skill，请停止，不要跨版本安装，并明确告诉我缺少的制品。
```

  </Tab>
