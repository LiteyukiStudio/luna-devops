# 部署平台

根据运行环境选择一种部署方式：

- [Kubernetes (Helm) 部署](/start/install/kubernetes)：适合长期运行和团队环境。
- [Docker Compose 部署](/start/install/docker-compose)：适合快速体验、小团队和测试环境。
- [二进制部署](/start/install/binary)：仅建议用于调试、离线排障或特殊环境。

部署完成后，从[初始化](/start/first-login)开始配置平台，再为用户[添加基础资源](/start/connect-resources)。需要接入监控时，参见[可观测](/reference/observability)。

部署新版本后，仍打开旧页面的用户会收到“网站已更新，请刷新页面”的提示；点击“刷新”后继续使用。页面不会自动刷新。
