# 日常交付

Luna DevOps 用一条清晰的路径把应用部署到集群：

```text
项目空间 → 应用 → 部署配置 → 构建或选择镜像 → 发布 → 访问入口
```

> **项目空间类似逻辑命名空间。** 它隔离不同产品或团队的成员、应用与资源，但不等同于 Kubernetes Namespace。

## 最短路径

1. [创建项目空间与应用](./project-space-and-apps)。
2. [创建部署配置](./deployment)，选择目标集群和运行规格。
3. 选择交付来源：
   - 有现成镜像：填写镜像地址并直接发布。
   - 只有源码：连接仓库，[构建镜像后发布](./build-and-release)。
4. 检查 Release 和工作负载达到可用状态。
5. 需要公网或自定义域名时，[创建访问入口](./routes)。

## 按需配置

- 使用环境变量、配置文件或 Secret：[配置与密钥](./configuration-and-secrets)
- 迁移一套部署参数：[部署配置导入与导出](./deployment-config-transfer)
- 保存数据库、上传文件等状态数据：[运行数据持久化](./runtime-data-persistence)

首次上线建议先用已有镜像验证“集群 → 发布 → 访问入口”，再接入源码构建和自动发布。这样更容易定位失败发生在哪一段。
