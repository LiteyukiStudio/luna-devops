# 首次部署引导（新手模式）

本 reference 用于**不了解服务器、容器化或 Kubernetes 的用户**。目标是把“我有个项目，
想让别人能访问”翻译成小白能听懂、能点选的几步，而不是直接抛出专业编排。

## 何时启用新手模式

满足任一条件时，本轮及后续对话切换到“教练语气”：

- 用户明确表示不熟悉：“我不会”“我不懂”“第一次”“新手”“小白”“没部署过”
- 用户反复询问概念：“什么是项目空间”“什么是镜像”“什么是集群”“Docker 是干嘛的”
- 用户连续两轮只回“嗯”“好”“你决定”“不知道”等无实质输入的内容

新手模式下：**每一步先用一句人话解释在做什么，再给操作**；不要连续堆叠三个以上
专业术语；能自动决定的（唯一候选）直接做，做完用一句话说明“我帮你选了 X，因为…”。

用户表现出熟悉（主动说出镜像、集群、端口、CI 等）后，退出新手模式，恢复正常编排。

## 术语人话对照

在新手模式或用户提问概念时，用下面的对照替换或补充专业词汇；正常模式不必使用。

| 术语 | 一句人话 |
| --- | --- |
| 项目空间 | 一个文件夹，装你这次要上线的东西，起个名字就行 |
| 镜像 | 把你的项目和它需要的运行环境打包好的“安装包” |
| 构建 | 平台帮你把代码做成上面的安装包 |
| 部署 / Release | 把安装包装到服务器上跑起来 |
| 工作负载 / Pod | 正在服务器上运行的你的应用 |
| 集群 | 一组服务器，平台帮你选，你不用管是哪台 |
| 端口 | 你的项目对外提供服务的门牌号，比如 3000 |
| 环境变量 | 你项目里的配置项，比如数据库地址、密钥 |
| 网关 / 域名 | 让别人能通过网址访问你的应用的入口 |
| 镜像站 | 存放上面“安装包”的仓库 |

## 首次部署五步向导

当用户表达“我想部署我的项目/网站/应用”“怎么让别人访问我的项目”且处于新手模式时，
优先走下面五步，而不是直接进入完整交付编排。每一步都给可点选的 `send_message` 选项。

### 第 1 步：了解项目（只问小白能答的）

用 `create_options` 或 `form` 收集，不要问 Dockerfile、构建上下文、镜像站：

- 项目类型：**前端页面** / **后端接口** / **前后端都有** / **我不确定**
- 本地启动命令：默认猜 `npm start` 或 `npm run dev`，让用户确认或修改
- 对外端口：默认猜 `3000`，让用户确认或修改

“我不确定”也是有效答案；选择后用读取工具自己判断，不要追问技术细节。

### 第 2 步：打包（解释构建）

一句人话：“我先把你的代码打包成能在服务器上运行的安装包，这一步叫构建，通常需要 1～3 分钟。”

- 项目没有 Dockerfile 时，主动说明：“你的项目没有 Docker 配置，我会用平台的默认
  模板帮你打包，只需要确认刚才那几个设置。”然后进入平台托管构建路径。
- 不要在这一步要求用户编写或理解 Dockerfile。

### 第 3 步：选个位置（解释项目空间）

一句人话：“给你这次要上线的东西找个文件夹放，起个名字就行。”

- 只有一个可用项目空间：直接采用，并说“我用现有的 `X` 来放，因为它已经是你的空间”。
- 没有或用户想新建：引导起名（如“我的第一个应用”），调用创建工具，不要让用户手填 ID。

### 第 4 步：跑起来（解释部署）

一句人话：“现在把安装包装到服务器上跑起来，好了我会告诉你。”

- 唯一集群/镜像站自动采用，不要让用户选。
- 状态用进度翻译（见下），不要说“工作负载未就绪”。

### 第 5 步：让别人访问（可选，解释域名）

一句人话：“现在只有服务器内部能访问。如果你想让别人通过网址打开，我帮你配一个入口。”

- 用户不需要公网访问时，第 4 步完成即交付终点，不要强行推进网关。
- 需要时，用平台提供的默认域名/后缀自动配置，避免让用户理解 DNS、证书。

## 异步状态进度翻译

新手模式下，把平台状态翻译成进度描述，技术状态放详情：

| 平台状态 | 新手版说法 |
| --- | --- |
| BuildRun 已提交 / 构建中 | 正在打包你的项目，通常需要 1～3 分钟 |
| Release 已提交 / 部署中 | 正在把包装到服务器上 |
| 工作负载未就绪 / Pod 启动中 | 应用正在启动，快好了 |
| 就绪 / Ready | 已经跑起来了 |
| 失败 / Failed | 出错了，我看看是什么原因 |

诊断结果在卡片顶部先给“一句话原因 + 一个建议操作”，日志和技术细节折叠在下方。

## 边界

- 新手模式只改变**解释方式和提问数量**，不改变权限、批准、MFA、验收或安全边界；
  高风险操作仍由平台机制门控，验收标准与 `task-completion.md` 一致。
- 用户明确要求专业操作或展示熟悉度后，退出新手模式，不再逐句翻译。
- 资源候选数量与自动采用规则仍按根 Skill 直接索引的 `resource-resolution.md` 执行，
  只是在新手模式下对自动采用的结果补一句人话说明。
