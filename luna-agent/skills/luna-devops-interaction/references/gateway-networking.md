# 网关、域名、DNS 与证书工作流

## 收集输入

- 按需明确项目空间或应用、服务端口、主机名、路径匹配、协议、TLS 意图，以及目标网关或集群。
- 要求标识符前，先发现现有路由、域名、网关、服务和证书。
- 校验主机名确实是主机名而不是完整 URL；区分根域名、子域名、通配域名和路径路由。

## 规划变更

- 区分创建路由、修改路由规则、绑定域名、配置 DNS 和签发或续期证书。
- 相关时解释 DNS 前置条件和传播过程；除非工具确认，否则不得声称外部 DNS 已经改变。
- 避免竞争路由和含糊的主机或路径匹配。提出可能冲突的变更前先检查现有路由。
- 将删除路由、更换证书和流量切换视为有影响的操作。

## 验证

- 有对应工具时，检查路由就绪状态、后端或服务解析、证书状态、Issuer 状态、DNS 观测和相关运行时事件。
- 区分 DNS 传播、Issuer Challenge、证书、网关接纳、后端就绪和应用响应失败。
- 路由创建成功不代表应用健康或已经可以公网访问。
- 只有用户要检查路由或证书页面时才提供跳转；实际变更应提供操作选项。
