# Luna DevOps 内部开发文档

本目录存放面向开发者的内部文档，与面向用户的公开文档站（`docs/docs/{zh,en}`）分离。`AGENTS.md` 是 AI 编码代理的硬约束入口，`CONTRIBUTING.md` 是贡献者协作入口，二者共同指向本目录。

## 文档分层

本目录只保留长期规范、长期边界和仍在进行的方案。已完成的实施方案、验收流水、问题记录和
导出产物不在这里长期归档；需要追溯时使用 `TODO.md`、Issue、PR 和 Git 历史。

## 边界

- 面向使用者和部署管理员的公开文档放 `docs/docs/{zh,en}`，不要把内部规范、方案、复盘写进公开文档站。
- 面向 AI 代理的硬性开发约束放 `AGENTS.md`；面向人类贡献者的协作流程放 `CONTRIBUTING.md`。
- 计划、验收与状态跟踪放 `TODO.md`。
- 已完成的实施方案、按日期累积的复盘和可再生成的图表/构建产物应删除，不迁入其他内部文档。
